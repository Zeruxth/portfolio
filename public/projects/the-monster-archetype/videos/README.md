# Videos — The Monster Archetype

Drop the videos here (MP4 preferred, under ~20MB each).

**Replacing an image?** Name the video after it:

| Tile on the page   | Name the video       |
| ------------------ | -------------------- |
| Glyphs             | `glyphs.mp4`         |
| Rorschach          | `rorschach.mp4`      |
| Emotions           | `emotions.mp4`       |
| Book — cover       | `book-cover.mp4`     |
| Spread A–F         | `spread-a.mp4` … `spread-f.mp4` |
| Book — open        | `book-open.mp4`      |
| Website            | `website.mp4`        |
| Screen A / B       | `screen-a.mp4`, `screen-b.mp4` |
| Social preview     | `social-preview.mp4` |

**New video, not replacing anything?** Any name works — Claude will look at it
and place it, or say where it goes (e.g. "after spread B").
